Ephemeral isolated environment only — synthetic credentials, egress allowlists, quotas. Hard gates fail certification outright (not a soft score). See docs/SECURITY-TEST-LAB.md.

  • authn / authz — tokens, tenant escape, env mismatch
  • input_safety — SQLi, traversal, shell metachar, oversized
  • ssrf_egress — metadata IPs, private ranges, DNS rebinding
  • data_protection — secret/PII/PHI redaction, size caps
  • prompt_injection — hostile issues/logs/docs/responses
  • reliability — timeouts, retries, circuit breakers, duplicates
  • approval_binding — arg mutation, replay, expiry, wrong identity
  • supply_chain — digest, signature, SBOM, vuln policy
  • auditability — correlation IDs, tamper-evident evidence, traces
  • full — all families + hard gates
